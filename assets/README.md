# Assets

This directory contains app assets including images, icons, and fonts.

## Structure

- `images/` - App images and book placeholders
- `icons/` - Custom icons
- `fonts/` - Custom fonts (Poppins family)

## Adding Fonts

Download the Poppins font family from Google Fonts and place the following files:
- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf

## Image Assets

Add your book placeholder images here:
- book_placeholder.png (default book cover)
